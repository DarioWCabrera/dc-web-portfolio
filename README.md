# DC Web Portfolio

Portfolio profesional de Dario Cabrera desarrollado con React y Vite.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Generar versión de producción

```bash
npm run build
```

Luego podés publicar la carpeta `dist` o conectar el repositorio a Netlify.

## Datos de contacto

Los enlaces de WhatsApp, correo, Instagram, LinkedIn y GitHub se encuentran al comienzo de `src/App.jsx`, dentro del objeto `CONTACT`.
